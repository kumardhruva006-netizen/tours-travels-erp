# Tours & Travels ERP Management System

A complete web-based ERP system for managing tours and travel businesses.

## Features
- ✅ Customer Management
- ✅ Package Management
- ✅ Booking Management
- ✅ Payment Tracking
- ✅ Inventory Management (Hotels, Transport, Guides)
- ✅ Reports & Analytics
- ✅ User Authentication

## Tech Stack
- **Frontend**: React
- **Backend**: Node.js + Express
- **Database**: PostgreSQL
- **Authentication**: JWT

## Project Structure
```
tours-travels-erp/
├── backend/           # Node.js API
├── frontend/          # React Application
├── database/          # SQL scripts
└── docs/             # Documentation
```

## Quick Start
1. Clone the repository
2. Follow setup instructions in each folder
3. Run backend and frontend servers
4. Access at http://localhost:3000

## Installation
See individual README files in `backend/` and `frontend/` directories.
